# YouthForge Product Backlog & Out-of-Scope Items

Per Section 7, V1 maintains a laser focus on the core loop: Idea Intake -> Targeted Clarification -> 5-Agent Pipeline -> Evidence-Backed Plan -> Progress Tracker -> Verifiable Portability.

## V2 / Post-Competition Backlog Items
1. Native iOS / Android wrapper with push notifications for milestone deadlines.
2. Team collaboration spaces (multi-seat youth teams with shared commenting).
3. Direct incubator & accelerator application exporter (custom formats for Dubai Future Accelerators, Hub71, etc.).
4. Real-time collaborative audio debriefing with agent personas.

## Explicit Anti-Scope (Will NOT be built)
- Token speculation, trading, or financial staking mechanisms.
- Public social feeds / vanity metrics.
- Automated unsolicited outreach / mass emailing to external people.
- Automated payment execution without human confirmation.
